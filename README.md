# stopmotools
A Blender addon for creating stop motion style animation

This addon makes stop motion style animation style transforms from existing keyframes on either rigged bones or regular objects. 
Basically it takes the selected objects in an animation, bakes down the animation to every frame, sets the animation keys to stepped, then deletes every other frame or every n frames.
It works in Blender 5.2 on my linux mint machine and that's about the extent of testing. 
I did use Gemini to help me get it working, so that's out there I guess.
Use at your own risk. Maybe a good idea to save your file before applying it.
IK controls must be baked over to FK before using it.
That's about all i can think of at the moment.
Good luck with it.
